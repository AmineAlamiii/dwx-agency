# Rental demo assets

Generated with the built-in imagegen tool on 10 October 2026. These are generic
illustrative vehicles for studio concepts, not photographs of a client's fleet.
Transparent originals remain in Codex's generated-images directory. Website
copies are resized, compressed WebP images with transparency preserved:

- `public/images/rental/compact.webp`
- `public/images/rental/suv.webp`
- `public/images/rental/electric.webp`

## Final prompt

Use case: product-mockup. Asset type: vehicle product image for a refined car
rental booking interface. Create a photorealistic studio product photograph of
**SUBJECT**. The entire vehicle is visible, front three-quarter view pointing
left, slightly elevated camera, realistic wheels, subtle soft contact shadow,
premium automotive catalog lighting, restrained reflections, detailed materials.
Landscape composition, vehicle occupies central 85% width, generous empty
transparent margins around its silhouette. Genuine transparent background.
No environment, no text, no logos, no visible brand insignia, no people, no
watermark. This is a generic illustrative rental vehicle, not a copy of a
particular manufacturer's model.

Subjects used, one generation each:

- Compact: a compact five-door hatchback in metallic silver.
- SUV: a premium mid-size SUV in very dark forest green.
- Electric: an elegant electric sedan in warm metallic champagne.
