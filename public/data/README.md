# Globe data

`land.json` contains rounded exterior land polygon coordinates derived from Natural Earth's 1:110m land dataset. Natural Earth data is public domain.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
License: https://www.naturalearthdata.com/about/terms-of-use/

The globe is an illustration of geographic reach, not a map of Dwx infrastructure or an assertion of office locations.
